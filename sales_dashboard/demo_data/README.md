# Demo Data Generator

This folder contains an independent script to generate sample data for the Sales Analytics Dashboard.

## Usage

Run the generator:
```bash
python generate_demo_data.py
```

This will create a `sample_sales_august_2026.xlsx` file.

You can upload this file in the Streamlit application to demonstrate its features.

**Note:** This folder is completely independent of the main application. You can safely delete it when transitioning to real data.
